## Rules

- Never modify Odoo core.
- Use custom addons.
- Prefer `_inherit`, ORM, stable hooks, and XML inheritance.
- Declare dependencies.
- Add access rights for new models.
- Review record rules.
- Validate syntax and XML when local Odoo is unavailable.
