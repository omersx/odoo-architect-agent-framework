# Workflow: Create Odoo Module

1. Read `SYSTEM.md` and `AGENTS.md`.
2. Analyze the business process.
3. Identify Odoo apps, models, views, reports, controllers, assets, security, and tests.
4. Choose hub module or industry extension.
5. Scaffold the addon.
6. Implement Python model logic.
7. Implement XML inheritance.
8. Add security files.
9. Validate syntax and XML.
10. Summarize install and acceptance checks.

Use `examples/custom_addons/biz_bridge_pro` as the reference hub implementation.
