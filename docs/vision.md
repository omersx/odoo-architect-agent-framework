# Vision

The Odoo Architect Agent Framework gives AI coding agents a professional Odoo engineering layer.

The goal is to move beyond one-off prompts and create a reusable, open-source toolkit for:

- Odoo technical architecture.
- Custom addon scaffolding.
- Agent instructions and skills.
- Multi-tool adapters.
- Static validation.
- Live Odoo smoke testing.
- Industry extension playbooks.

## Direction

The framework should grow toward a product-grade developer tool:

- `odoo-architect scaffold`
- `odoo-architect validate`
- `odoo-architect review`
- `odoo-architect smoke-test`
- Future eval datasets for generated Odoo addon quality.
- Future richer scaffolds for models, views, controllers, reports, OWL, POS, and website modules.

The long-term target is a community-maintained Odoo agent framework that helps developers, consultants, and teams produce safer Odoo customizations.
