## Step 1: Architecture

Review the requirement and produce a functional specification, technical design, dependencies, data model, security model, views, and test plan. Do not write code yet.

## Step 2: Scaffold

Create the Odoo addon folder structure, `__manifest__.py`, package imports, and empty target files. Do not write business logic yet.

## Step 3: Backend

Implement the Python model inheritance, fields, methods, hooks, constraints, and tests using Odoo conventions.

## Step 4: Views

Implement XML view inheritance with stable XPath targets. Do not replace large standard view blocks.

## Step 5: Security

Add access rights for new models, review record rules, and explain why inherited models do or do not need new rights.

## Step 6: Review

Review the addon for install risk, dependencies, security, multi-company behavior, upgrade compatibility, and missing tests.
