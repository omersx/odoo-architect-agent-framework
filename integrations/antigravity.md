# Antigravity

Antigravity integration files live under `.agents/`.

## Files

- `.agents/rules/odoo-architect.md`: persistent Odoo engineering rules.
- `.agents/agents/odoo-architect/agent.md`: specialized Odoo Architect agent role.
- `.agents/workflows/create-odoo-module.md`: workflow for creating addons.
- `.agents/skills/odoo-architect/SKILL.md`: portable skill-style instructions.

## Usage

Point Antigravity at this repository and use the Odoo Architect agent/rules when creating or reviewing addons.

The adapter is intentionally markdown-based. If your Antigravity version expects a stricter schema, keep the body text and adapt the metadata wrapper.
