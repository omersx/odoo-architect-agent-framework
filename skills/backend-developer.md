# Skill: Backend Developer

Use this role for Python models, ORM logic, constraints, computed fields, cron jobs, server actions, and tests.

## Rules

- Use `_inherit` for standard models.
- Use `self.ensure_one()` for button methods.
- Keep computed fields deterministic.
- Use Odoo exceptions for business validation.
- Use hooks where Odoo provides them.
- Add tests for accounting, stock, pricing, permissions, and automated creation logic.
