# Engineering Principles

- Build upgrade-safe customizations.
- Prefer clear model methods over large automated action code blocks.
- Keep files small and named after the model or view they affect.
- Avoid clever abstractions unless they remove real duplication.
- Make failures understandable to functional users.
- Use translatable strings for user-facing messages.
- Keep demo data separate from production data.
- Use tests for pricing, stock, accounting, automated transitions, security, and integrations.
