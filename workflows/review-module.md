# Workflow: Review Module

Review in this order:

1. Manifest dependencies and data loading order.
2. Python imports and model inheritance.
3. Field definitions and storage behavior.
4. Business methods and hooks.
5. XML inheritance and XPath stability.
6. Security access and record rules.
7. Multi-company and multi-currency behavior.
8. Tests and upgrade risks.

Lead with concrete findings. Include file paths and line numbers when available.
