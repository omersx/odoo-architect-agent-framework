# Workflow: Analyze Requirements

Use this before writing code.

1. Identify the business outcome.
2. Identify the Odoo apps involved.
3. Identify standard Odoo behavior that already exists.
4. Identify new fields, workflows, reports, integrations, and permissions.
5. Decide whether the feature belongs in the hub module or an industry extension.
6. List assumptions and unresolved questions.
7. Produce a functional specification and a technical design.

## Output Format

- Business process summary.
- Affected models and modules.
- Proposed addon boundary.
- Data model.
- UI changes.
- Security impact.
- Test plan.
- Open questions.
