# Module Workflow

1. Summarize the business process.
2. Identify affected Odoo apps and models.
3. Decide the custom addon boundary.
4. Declare dependencies.
5. Scaffold module files.
6. Implement models and hooks.
7. Implement XML views with stable XPath.
8. Add security for new models.
9. Add tests or a focused test plan.
10. Validate install risks and document acceptance checks.

## Required Output

- Functional summary.
- Technical design.
- Files changed.
- Security impact.
- Verification steps.
