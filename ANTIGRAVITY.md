# Antigravity Adapter

This repository includes Antigravity-friendly files under `.agents/`.

Suggested mapping:

- Rules: `.agents/rules/odoo-architect.md`
- Agent: `.agents/agents/odoo-architect/agent.md`
- Workflow: `.agents/workflows/create-odoo-module.md`
- Skill: `.agents/skills/odoo-architect/SKILL.md`

The adapter files point back to the shared framework:

- `SYSTEM.md`
- `AGENTS.md`
- `workflows/`
- `patterns/`
- `checklists/`
- `templates/`
- `industries/`

Use `biz_bridge_pro` as the reference addon and create `biz_bridge_[industry]` modules as spokes.
