# Review Checklist

- Does the module install on a clean database?
- Does it upgrade without XML ID conflicts?
- Are dependencies complete?
- Are hooks correct for the target Odoo version?
- Are views resilient to common upstream changes?
- Are access rights least-privilege?
- Are error messages useful to users?
- Are business-critical paths tested?
- Are version-sensitive areas called out?
- Has the static validator passed?
- Has the module been installed and updated on the target Odoo version?
